# Support

## Getting help

- Read `README.md` for setup and usage.
- Read `network-stability-test-gui.md` for GUI-specific behavior.
- Run smoke/tests to validate local setup:
  - `powershell -NoProfile -ExecutionPolicy Bypass -File ".\validation\gui_modular_smoke.ps1"`
  - `Invoke-Pester -Path .\tests`

## Ask a question

Use GitHub Issues with:

- Environment details (Windows version, PowerShell version)
- What you tried
- Relevant logs/output

## Bug reports

Use the Bug Report template and include:

- Reproduction steps
- Expected vs actual behavior
- Attachments (logs/screenshots) when possible
