# Code of Conduct

## Our pledge

We are committed to providing a welcoming, respectful, and harassment-free
experience for everyone participating in this project.

## Our standards

Examples of positive behavior include:

- Being respectful and constructive
- Accepting feedback gracefully
- Focusing on what is best for the project and community

Examples of unacceptable behavior include:

- Harassment, insults, or discriminatory language
- Trolling or personal attacks
- Publishing private information without permission

## Enforcement

Project maintainers are responsible for clarifying and enforcing this code of
conduct and may remove, edit, or reject comments, commits, code, and other
contributions that violate these standards.

## Scope

This code of conduct applies in all project spaces, including repository
issues, pull requests, discussions, and related communication channels.

## Reporting

Report behavior concerns to project maintainers via GitHub.
