# Security Policy

## Supported versions

Security fixes are provided for the latest state of the `main` branch.

## Reporting a vulnerability

Please do not open public issues for potential security vulnerabilities.

Instead:

1. Open a private GitHub Security Advisory for this repository, or
2. Contact the maintainer directly through GitHub.

Include:

- Affected version/commit
- Reproduction details
- Impact assessment
- Any known mitigations

You can expect an initial response within 7 days.
